# API reference

Use the current [API reference map](/docs/api) to distinguish the running
router, embedded OpenAPI/Swagger summary, hosted rustdoc and TypeDoc, and
narrative protocol guides.

For wire behavior, continue to
[HTTP compatibility](/docs/protocols/http-compatibility) and
[Events, AG-UI, and A2UI](/docs/protocols/events-and-ui).

The [canonical execution and recovery contract](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/main/docs/product-support-matrix.md#execution-and-recovery-guarantees)
defines interface-specific admission, restart, retention/cursors, retries and
uncertain-effect handling. The [finite final checklist](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/main/docs/releases/v1.4.0-final.md)
records current unverified selected-image obligations. Generated API shape and a
reusable run/session ID are not acceptance evidence or automatic replay authority.
