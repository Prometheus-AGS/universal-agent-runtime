# TypeScript SDK

The UAR TypeScript SDK (`sdks/typescript`) mirrors the Rust SDK surface and uses `fetch-event-source` for streaming and `zod` for runtime validation.

## Installation

```bash
npm install @prometheus-ags/universal-agent-runtime-sdk
```

## Reference

- [Generated TypeDoc for the TypeScript SDK](https://prometheus-ags.github.io/universal-agent-runtime/docs/api/typescript)
