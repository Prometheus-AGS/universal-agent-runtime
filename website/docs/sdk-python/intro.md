# Python SDK

The UAR Python SDK (`sdks/python`) mirrors the Rust SDK surface and uses `httpx-sse` for streaming and `pydantic` for typed models.

## Installation

```bash
pip install universal-agent-runtime
```

## Reference

- Sphinx autodoc is generated from `sdks/python/` and published alongside the rest of the documentation.

## Examples

Examples live in `sdks/python/examples/`.
