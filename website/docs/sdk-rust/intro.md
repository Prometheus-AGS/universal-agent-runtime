# Rust SDK

The UAR Rust SDK (`sdks/rust`) provides typed access to the runtime API, including streaming chat, tool calls, structured outputs, and run lifecycle management.

## Installation

Add the SDK to your `Cargo.toml`:

```toml
[dependencies]
universal-agent-runtime-sdk = "1"
```

## Reference

- [Generated rustdoc for the Rust SDK](https://prometheus-ags.github.io/universal-agent-runtime/docs/api/rust)
- [Runtime rustdoc](https://prometheus-ags.github.io/universal-agent-runtime/docs/api/rust) (when published from the workspace)

## Examples

Examples live in `sdks/rust/examples/` and are run with `cargo run --example <name>`.
