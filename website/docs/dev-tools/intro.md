# Development tools

Use [Tools and trusted-host execution](/docs/tools/overview) for native and MCP
tool discovery, schemas, policy, approval, execution, and the loopback-only
`uar-jwt-proxy` workflow.

The proxy is a local development aid, not a deployed identity gateway. MCP
server configuration and reconnect behavior are documented under
[MCP](/docs/protocols/mcp).
