# Architecture

This section describes the high-level architecture of the Universal Agent Runtime (UAR).

## Overview

UAR is a tool-first, streaming-native agent runtime written in Rust. It exposes an Axum HTTP API, a React 19 operator interface, and a set of SDKs for Rust, Python, and TypeScript.

## Key topics

- Architecture overview
- A2A protocol support
- State management
- Memory system
- RAG subsystem
- A2UI surface

For generated API details, see the [API reference](https://prometheus-ags.github.io/universal-agent-runtime/docs/api).
