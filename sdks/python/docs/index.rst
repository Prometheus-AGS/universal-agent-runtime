Universal Agent Runtime Python SDK
==================================

Install with ``pip install universal-agent-runtime-sdk`` and construct an async
``Client`` with the URL of a running UAR server. The package is suitable for
ReadTheDocs and GitHub Pages; build this site with
``sphinx-build -W -b html docs docs/_build/html``.
