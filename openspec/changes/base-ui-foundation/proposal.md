# Change: Base UI Foundation — Package Swap + shadcn CLI Regen

## Why

The frontend currently depends on 27 individual `@radix-ui/*` packages. Radix UI has known bugs
around combobox infinite refresh, dropdown position flicker, and Slot/asChild composition edge cases.
Base UI v1.5.0 (May 2026), built by the same MUI team, fixes these structurally via Floating UI
positioning and an explicit `render` prop model. The shadcn CLI officially supports `"style":
"base-vega"` as of December 2025, allowing automatic regeneration of all 46 UI primitive components.

This change performs the foundational swap: remove all Radix packages, install `@base-ui/react`,
update `components.json`, and run the shadcn CLI to regenerate all UI components. Subsequent changes
handle icon migration, composition patterns, and verification.

## What Changes

- Remove all 27 `@radix-ui/*` primitive packages and `@radix-ui/react-slot` from `frontend/package.json`
- Add `@base-ui/react` (v1.5.0) and `@floating-ui/react` to `frontend/package.json`
- Update `frontend/components.json`:
  - `"style"` → `"base-vega"`
  - `"baseColor"` → `"neutral"`
- Back up current `frontend/src/components/ui/` to `frontend/src/components/ui-radix-backup/` before regen
- Run `pnpm dlx shadcn@latest add --all --overwrite` to regenerate all 46 UI component files
- Verify TypeScript compiles without errors after regen (icon errors expected — fixed in next change)

## Files Affected

- `frontend/package.json` — dependency changes
- `frontend/components.json` — style change
- `frontend/src/components/ui/*.tsx` — all 46 files regenerated by shadcn CLI
- `frontend/src/components/ui-radix-backup/` — created as safety net

## Out of Scope

- Icon replacement (`@radix-ui/react-icons` → `lucide-react`) — handled in `base-ui-icon-migration`
- `asChild` → `render` rewrites — handled in `base-ui-composition-patterns`
- `cmdk` / `assistant-ui` audit — handled in `base-ui-verification`

## Acceptance Criteria

- [ ] `frontend/package.json` contains zero `@radix-ui/*` entries (except `@radix-ui/react-icons` which is deferred)
- [ ] `frontend/package.json` contains `@base-ui/react` and `@floating-ui/react`
- [ ] `frontend/components.json` has `"style": "base-vega"`
- [ ] `frontend/src/components/ui/` contains Base UI–backed component implementations
- [ ] `pnpm install` succeeds
- [ ] `pnpm typecheck` produces only icon-related errors (no primitive errors)
