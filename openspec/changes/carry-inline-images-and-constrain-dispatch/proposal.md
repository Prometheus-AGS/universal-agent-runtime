# Carry inline images and constrain actual model dispatch

## Why
Ordinary chat strips image parts or turns attachments into descriptive JSON, while runtime selection supplies preference-only requirements and can rescue a failed route through an unconstrained preferred configuration. Catalog metadata therefore overstates delivered vision and constrained dispatch. Required#462baseline is now available;#463/#464share the actual payload/destination contract and must preserve#388.

## What Changes
- Preserve admitted current-turn inline PNG/JPEG parts on two existing ordinary OpenAI aliases through canonical session/checkpoint history to the actual compatible provider adapter. Keep derived matching/guardrail/memory/context text separate.
- Explicitly refuse unsupported, malformed or bounded-size/count-invalid forms before dispatch; keep diagnostics free of raw images. Existing direct Anthropic behavior stays intact and independently unqualified.
- Reuse one capability/availability evaluator for advisory routing and actual primary/retry/fallback/graph sends; capture only real bound destination identities, preserve exact-target and authority constraints.
- Preserve final-destination settings/context/output/reasoning/protected-group budgeting. Unknown real image accounting cannot claim guaranteed fit.
- Extend existing mounted HTTP behavior tooling and correct support evidence claims. Deterministic wiring is not genuine visual understanding or release qualification.

## Capabilities

### New Capabilities
- `inline-image-chat`: bounded typed ordinary-chat image admission, lossless canonical transport, safe diagnostics and explicit unsupported forms.
- `constrained-model-dispatch`: hard request capabilities and immutable captured destination scope enforced at every actual send.

### Modified Capabilities
None. Existing context-budget behavior is preserved, not replaced.

## Impact

No UI, vendor source, dependency upgrade, new kernel/global runner, full-harness durability rewrite, public allow/deny DSL, image fetching, signing, deployment or paid calls.
