## Contracts

Use existing MessageContent/ContentPart, not JSON text. Proposed new crate-private RunExecutionRequest.current_user_content and with_admitted_current_user_content preserve text constructor compatibility; input holds every text part in order joined by newline and never an image URL. The manager appends one canonical user Message at all3existing seams, including inherited/checkpoint paths. Image-only content remains present.

Ingress admits last current user content only, rejects earlier ignored image replay/ambiguous convenience input, and retains existing text attachment behavior. New input is at most8PNG/JPEG inline images within the10MiB whole request cap; existing xberg decoded/live100MiB limit is explicitly selected. Strict standard padded base64/MIME/detail and actual decoder acceptance are distinct checks. Existing xberg public bytes API is used with cache/OCR/postprocessing/quality processing disabled, no URI/network path, owned/joined work and bounded concurrency. Minimal/non-document profile refuses images. Bounds trace to untrusted public decoder work, not an inferred provider token allowance.

New shared helper in src/llm/inline_image.rs owns syntax/bytes validation and safe errors; ingress owns its source, provider owns mod.rs export. Canonical history projection may preserve only admitted supported inline content, while text/tool arguments/generic state/errors/logs keep secret scrubbing. Checkpoint projection changes only canonical messages, never state authorization/data. Invalid/unqualified values do not create a generic scrubber escape. Use explicit helper contract handoffs before consumers are edited.

Provider-owned DestinationScope has Exact{primary} or PrimaryWithFallbacks{primary,fallbacks:BTreeSet}; no Unboundvariant. Runtime creates it only from actual captured RunModelBindings identities, never global catalog/credential grants/configuration prose. Provider-owned DestinationAdmission::admit(destination,&final_requirements) rechecks enabled/cooldown/declared hard capabilities against that immutable scope. Captured driver/adapter construction facts are distinct from model metadata. Any necessary narrow default trait query in llm/mod.rs describes adapter passthrough capability, not authorization or certification.

ModelRouter uses the same evaluator; runtime explicit provider/model disablement vetoes catalog supplementation. Metadata declarations retain compatibility, including current tools defaults; no global provenance schema redesign or unsupported claim of certification. Final demands come from retained/current images, actual nonempty tools/required selection, structured output, and explicit admitted reasoning controls. Optional reasoning output and mere existence of a registry are not hard requirements. Existing context/cost semantics remain; final budget compilation decides actual capacity.

Orchestrator primary retry/fallback checks occur after each destination's prepare_user_attempt and format controls, before open_driver_stream; graph DestinationBudgetDriver applies its captured budget/cap then admission before forwarding. Rejection is admission failure, not provider outage or new fallback grant. Exact targets do not substitute. No-registry/no-match required capability refuses; no preferred-config escape. Private helper requests derive their own demands.

Keep#388templates/settings/endpoint and wire identity, output/reasoning reserves, protected tool/image groups and per-fallback preparation. Real guaranteed-fit or finite accounting requiring unproven image count refuses before send; estimated lane truthfully reports no fit guarantee. Only existing explicitly synthetic exact JSON fixtures may prove that synthetic contract. Do not hardcode a model-name bypass or invent real image token allowances. Existing native Anthropic/direct conversion is not blanket-disabled by the new ordinary-route contract.
