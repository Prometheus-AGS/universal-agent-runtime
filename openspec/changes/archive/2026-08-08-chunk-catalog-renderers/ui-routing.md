## Unavailable required-route skills

C-12 uses the repository standards above, focused automated checks, catalog stories, manual keyboard/responsive review, the a11y gate, and an isolated adversarial review as the documented fallback.

## Task-specific distillation

The chunk catalog must stay calm and inspectable: visible chunks use filled surfaces and explicit state language; secondary detail begins collapsed; protocol dividers are spacing; trace-only events never become prose; every control is named and keyboard-operable; untrusted artifacts keep their existing sanitizer, sandbox, or policy boundary; and chart payloads supply data only while the application owns presentation.
