# Change: Base UI Foundation — Package Swap + shadcn CLI Regen

## Capabilities

- `frontend-component-primitives`

> **Archive reconciliation (2026-08-07):** The delivered production wrappers use
> Base UI and the generator metadata remains `base-vega`/`neutral`. Direct Radix
> imports are absent from production source. Radix declarations later reappeared as
> unused manifest entries; their transitive audit and removal are owned by
> `retire-admin-and-legacy-deps` (C-14c), so they are not asserted by this change's
> durable capability specification.

## Why

At proposal time, the frontend depended on 27 individual `@radix-ui/*` packages. Radix UI has known bugs
around combobox infinite refresh, dropdown position flicker, and Slot/asChild composition edge cases.
Base UI v1.5.0 was the evaluated baseline; the current tree pins v1.6.0. Base UI fixes
these issues structurally via Floating UI
positioning and an explicit `render` prop model. The shadcn CLI officially supports `"style":
"base-vega"` as of December 2025, allowing automatic regeneration of all 46 UI primitive components.

This change performs the foundational source migration: move production wrappers from direct
Radix imports to `@base-ui/react`, update `components.json`, and regenerate the UI wrappers.
Subsequent changes handle icon migration, composition patterns, verification, and the final
transitive dependency-declaration prune.

## What Changes

- Remove direct `@radix-ui/*` imports from production UI wrappers
- Add `@base-ui/react` as the production primitive foundation
- Update `frontend/components.json`:
  - `"style"` → `"base-vega"`
  - `"baseColor"` → `"neutral"`
- Run `pnpm dlx shadcn@latest add --all --overwrite` to regenerate all 46 UI component files
- Isolate composition, icon, and dependency-pruning follow-ups in their named changes

## Files Affected

- `frontend/package.json` — dependency changes
- `frontend/components.json` — style change
- `frontend/src/components/ui/*.tsx` — all 46 files regenerated by shadcn CLI

## Out of Scope

- Icon replacement (`@radix-ui/react-icons` → `lucide-react`) — handled in `base-ui-icon-migration`
- `asChild` → `render` rewrites — handled in `base-ui-composition-patterns`
- `cmdk` / `assistant-ui` audit — handled in `base-ui-verification`
- Final Radix manifest-declaration audit and prune — handled in C-14c
