# C10.2 governed connector effects

This repository-scoped change implements C10.2 in initiative change `afc-c10-feedback-workflow-and-governed-connector-effects`. UAR owns connector grant and effect identities. The trusted host retains credential values and performs outbound HTTP; UAR never persists a token or grants a model arbitrary HTTP access.

Implement typed GitHub issue, Notion, Slack and Jira request plans, separate read/draft/write/send/publish grants, exact target and egress-label checks, durable pre-dispatch intent, one dispatch lease, terminal receipt and explicit uncertain-outcome reconciliation. C10.3 owns intake policy and BossFang ingress.
