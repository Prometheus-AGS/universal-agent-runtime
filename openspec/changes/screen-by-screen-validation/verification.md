## Observed defects repaired

The certification work exposed three supported-product defects rather than test
flakiness: Skills ignored live graph rows without a list index,
approval-required events did not reach the chat/runtime graph, and Knowledge
cards nested one button inside another. The operator approved correction before
execution, but canonical plan revision 7 was projected after the repairs. The
immutable process-waiver decision records that defect instead of rewriting its
chronology. A later source-bound run also exposed a test-boundary defect: the
exact-answer assertion selected the whole multi-part assistant message and
therefore included a valid sibling A2UI artifact. The correction targets only
the assistant text part without weakening its exact regex. The final candidate
supersedes every earlier evidence bundle.
