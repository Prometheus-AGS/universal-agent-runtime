## Why

The freeze and dead session override survived because existing validation did not constrain render-body setters, unbounded graph publication loops, feature-layer graph bypasses, or the claimed inference effect. A small set of executable boundaries and one short installed-browser proof must prevent the same architecture from returning.

## What Changes

- Add repository instructions, including the TypeScript/React rule loaded for frontend edits, that require Vercel React Best Practices, Composition Patterns, and the applicable Prometheus Entity Management skills before React/entity-state work and distinguish entity-backed state from transient Zustand state.
- Add narrowly scoped static checks for synchronous render-body state setters, per-row graph mutations in feature code, direct entity-package imports outside the platform facade, and duplicate entity caches for graph-owned session/provider/model state.
- Add a bounded local installed-service browser scenario covering responsiveness, configured-model loading, save/reopen, cancel isolation, effective inference, resolved spacing, console/network evidence, and matching server logs.
- Keep all product verification local; GitHub Actions remain deployment-only.
