# Design: Hosted docs portal with Docusaurus, Vale, and ADRs

## Overview

Change 23 delivers the minimum viable developer portal infrastructure for the UAR grade-A release.

## Architecture

```
Root package.json
  ├── docs:start   → npm --prefix website start
  ├── docs:build   → npm --prefix website run build
  └── docs:lint    → npm --prefix website run lint

website/
  ├── docusaurus.config.ts  (navbar, footer, baseUrl, GitHub Pages URL)
  ├── sidebars.ts           (autogenerated from docs/ with _category_.json)
  ├── docs/
  │   ├── architecture/
  │   ├── configuration/
  │   ├── sdk-rust/
  │   ├── sdk-python/
  │   ├── sdk-typescript/
  │   ├── rag/
  │   ├── a2ui/
  │   ├── governance/
  │   ├── supply-chain/
  │   ├── contributing/
  │   └── api/
  └── scripts/lint-docs.mjs (runs Vale when installed)

docs/adr/
  ├── 0001-record-architecture-decisions.md (template)
  ├── 0002..0011 (10 grade-A ADRs)
  └── index.md

.github/workflows/docs.yml
  → Vale lint → copy ADRs → Docusaurus build → rustdoc → TypeDoc → deploy Pages

.vale.ini + .github/styles/UAR/
  → UAR-specific prose lint rules and vocabulary
```

## Decisions

- The Docusaurus site already lives in `website/` using npm. We keep it there and add root npm scripts that delegate to npm in `website/`.
- ADRs are authored in the canonical `docs/adr/` directory and copied into `website/docs/adr` at build time so they appear on the portal.
- Vale is not bundled as an npm dependency (no official package). The `docs:lint` script checks for a local Vale installation and degrades gracefully; CI installs Vale via `errata-ai/vale-action`.
- API reference links use the published GitHub Pages URL because the generated rustdoc/TypeDoc files are static and not Docusaurus routes, so Docusaurus's broken-link checker would otherwise flag them.
- The GitHub Pages workflow uses npm ci for `website/` and `sdks/typescript/`, and `dtolnay/rust-action` for rustdoc generation.

## Verification

- `npm run docs:build` produces a clean Docusaurus build with no broken links.
- `npm run docs:lint` runs Vale with 0 errors on the new documentation.
- `openspec validate docs-hosted-rustdoc-typedoc-docusaurus-ia` passes.
- `cargo check` was not required because no Rust source files were modified; the workflow includes a placeholder rustdoc step.
