The route cohort now has explicit coverage for exact model selection, tenant deny-final policy, protected fit, and a host-owned shared cost/latency ledger spanning root work, classifier calls, summaries, retries and children. Synthetic fixtures prove arithmetic and wiring only. Live claims remain blocked until paired held-out evidence exists for each certified exact deployment.
