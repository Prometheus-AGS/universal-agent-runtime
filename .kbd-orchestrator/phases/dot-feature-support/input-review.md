2. **P1 before shared hosting — key provider credentials by verified issuer, subject, and tenant.** **Still open; static.** [Credential API identity extraction](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/api/credentials.rs#L76-L83) reduces the caller to `user_id`; [writes](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/api/credentials.rs#L159-L166) and [Postgres uniqueness](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/security/credentials/store.rs#L437-L450) use only scope, scope ID, and provider. [Resolution](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/security/credentials/resolver.rs#L55-L74) likewise has no tenant/issuer argument. Two authenticated identities sharing a subject across tenants or issuers can collide in a shared credential store, causing overwrite/deletion or use of the wrong provider account. Encryption at rest does not separate these identities.

   **Action:** carry a verified principal key through API, storage, resolution, and session/agent ownership; migrate existing rows explicitly. **Acceptance:** two tenants and two issuers with the same subject can independently put/list/delete/use the same provider's credentials; cross-scope access is denied and legacy rows cannot be silently claimed. This concerns stored provider credentials, not a claim that all host contexts lack tenant scoping.

3. **P1 — propagate MCP application failure into tool and admission receipts.** **Still open; static.** The [registry](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/mcp/registry.rs#L2348-L2355) measures success from RPC `Result::is_ok()` and [returns the serialized result](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/mcp/registry.rs#L2467-L2468). The [orchestrator MCP branch](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/llm/orchestrator.rs#L712-L749) then returns `true` without checking `isError`. [Terminal receipt handling](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/llm/orchestrator.rs#L636-L650) passes that boolean to [durable admission evidence](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/runtime/tool_admission/lifecycle.rs#L264-L273). A tool-reported failure can therefore be recorded as succeeded, misleading BossFang, subsequent team steps, and audit views.

   **Action:** preserve the full MCP result while distinguishing transport failure, application failure, and successful execution. **Acceptance:** a real MCP fixture returning `isError: true` yields failed ToolEnd/admission/host receipts, retains its error content, and does not automatically replay a possibly effected call. A successful result and a transport-unknown outcome remain distinct.

4. **P1 — make stream completion and Anthropic framing correct on every supported route.** **Improved but incomplete already at baseline; unchanged by #369; static.** [Liter requires a terminal event only when an endpoint profile exists](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/llm/liter_driver.rs#L599-L600); [otherwise EOF becomes Done](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/llm/liter_driver.rs#L751-L755). The orchestrator's [terminal guard is conditional](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/llm/orchestrator.rs#L2344-L2353), so strict graph/profile behavior does not establish universal completion safety. Separately, [native Anthropic parsing](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/llm/anthropic_driver.rs#L380-L403) applies lossy UTF-8 decoding and newline splitting to each transport chunk, then [clears state at apparent blank lines](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/llm/anthropic_driver.rs#L430-L443). Split prefixes, JSON lines, or multibyte characters can be dropped or corrupted; parse failures are silently ignored.

   **Action:** use incremental byte/SSE framing and require a protocol-confirmed terminal outcome independent of endpoint-profile selection. **Acceptance:** existing production driver paths pass chunk-boundary scenarios for every byte split, UTF-8, CRLF, malformed events, and early EOF; interrupted output is never recorded as completed. Exercise the orchestrator boundary as well as parsed event helpers.

5. **P1 — make checkpoint resume survive a process restart and expose backend support honestly.** **Improved but incomplete already at baseline; static.** Protected checkpoint history and authorization binding exist. However, [resume first requires the original run](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/api/routes.rs#L1464-L1467), and that lookup [only reads active_runs](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/runtime/manager.rs#L7279-L7304), before [loading the durable checkpoint](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/api/routes.rs#L1501-L1503). A stored checkpoint alone cannot restore a run after restart. The persistence trait still [defaults to successful no-op save and empty reads](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/persistence/mod.rs#L614-L635); Postgres has no checkpoint override. A [checkpoint node can log “Checkpoint persisted”](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/runtime/graph/nodes/checkpoint_node.rs#L77-L90) after that no-op.

   **Action:** persist the minimum run identity, artifact/binding, and host-resource references needed to reconstruct resume authorization; rebind secrets through the host. Implement Postgres checkpoint persistence or report unsupported capability before offering resume. **Acceptance:** terminate and recreate the process, resume a checkpoint with the original protected history and authority, reject a different tenant or changed binding, and report checkpoint storage failure truthfully. Keep this separate from the durable agent-instance recovery that already exists.

6. **P1 for document-backed work — durably accept upload bytes and ingestion jobs together.** **Still open; static.** [Upload saves a Pending document with no file path](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/api/knowledge.rs#L441-L459), passes bytes into the worker pool, and [returns 202 even if submission fails or no pool exists](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/api/knowledge.rs#L461-L488). The [queued job owns an in-memory byte vector and has no idempotency key](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/rag/ingestion_worker.rs#L441-L468). A restart or enqueue failure can leave a visible document without recoverable source bytes or a durable job.

   **Action:** persist source content plus an idempotent job/outbox before acknowledging acceptance, then lease and reconcile jobs. **Acceptance:** kill after 202, before dispatch, and during indexing; restart automatically completes or exposes a durable actionable failure. Retrying must not duplicate chunks, and failed enqueue cannot silently strand a Pending record.

7. **P1 for external clients — wire durable API-key storage into server startup.** **Still open; static.** Despite issuer/tenant-aware key records and management authorization, [server startup always creates InMemoryApiKeyStorage](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/server.rs#L1355-L1363). Managed keys disappear on restart and are unavailable to another server process, breaking BossFang integrations and unattended clients.

   **Action:** implement the existing storage interface for the selected production backend, retaining hashes, authority metadata, expiry and revocation. **Acceptance:** create, restart, authenticate, revoke, restart again, and confirm denial; repeat across two processes sharing the supported backend. Preserve the existing authority restrictions; this is a storage/wiring gap.

8. **P1 for spend enforcement — commit usage idempotently and restore aggregate budgets.** **Improved but incomplete already at baseline; static.** Completed and cancelled runs share cost settlement, and durable cost-history providers exist. But [settlement spawns independent fire-and-forget writes](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/runtime/run_cost.rs#L61-L80), while [the persistence contract describes the tracker as in-memory](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/persistence/mod.rs#L642-L648). Process exit or database failure can lose ledger entries after a terminal outcome; a restarted tracker is not durable account-wide budget authority.

   **Action:** persist an idempotent usage event keyed by run/call, await durable acceptance or use an outbox, and hydrate/reconcile the enforcing ledger before admitting more work. Define shared-host reservation ownership before claiming cross-process ceilings. **Acceptance:** crash at settlement, inject a database outage, replay the same receipt, and restart; ledger totals remain exact once, aggregate limits survive, and unresolved usage/reservations are visible. Existing [settlement tests poll spawned writes](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/tests/run_cost_settlement.rs#L46-L55); that is not crash-consistency evidence.

9. **P1 for an always-on team service — add trusted recovery from an abruptly dead execution owner.** **High-value missing recovery path; static inference.** Non-expiring claims are a safety improvement, not something to replace with timeouts. [Acquisition refuses a held predecessor](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/compiler/collaboration/team_execution/ownership.rs#L40-L49), and [reclaim accepts only persisted trusted-runtime-joined evidence](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/compiler/collaboration/team_execution/ownership.rs#L119-L137). The only production insertion found is [the old owner's joined path](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/uar/compiler/collaboration/team_execution/ownership.rs#L74-L101). If the owner dies before recording that evidence, the next executor [boots with a read-only team catalog](https://github.com/Prometheus-AGS/universal-agent-runtime/blob/3327bf99e48097479313c8a54e8e58d1de9e9ccb/src/server.rs#L1385-L1389).

   **Action:** define a trusted supervisor/operator fencing proof for a dead incarnation, and an audited reconciliation path for uncertain attempts. **Acceptance:** hard-kill the executor, prove its roots and children cannot act, reclaim with an incremented epoch, resume only safe queued work, and preserve uncertain external effects for reconciliation. A stale still-running executor must fail every subsequent claim. This extends current safe ownership semantics rather than weakening them.
