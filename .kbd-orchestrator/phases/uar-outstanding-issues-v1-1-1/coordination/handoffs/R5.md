  peer that supports OpenAI-compatible and native Anthropic SSE paths. The mode

  MCP peer matrix with omitted outcome status, JSON-RPC failure, response
  timeout, and post-effect disconnect.

The adapter executes the `streams` group. It returns declared `blocked` scenarios
for `binding`, `mcp-outcomes`, and `combined` until the lead installs the actual
T4/S4/L2 public collaborator configuration. This is deliberate truthful gate
behavior, not a passing result: the runner turns any such scenario into a blocked
receipt. Required inputs are the exact credential/migration fixture routes,
durable eligibility configuration, and model-driven MCP registration/grant shape.

No test, build, formatter, lint, compiler/import probe, schema validation, or
review ran. The stream peer/adapter, test fixtures, and documentation remain
unverified.
