# T2 source handoff — model credential binding seams

Changed paths:

- `src/uar/runtime/manager.rs`: adds the startup-owned
  `RunManager::with_credential_policy(Arc<CredentialTenancyPolicy>)` builder;
  resolves a policy decision for the final primary route and every fallback before
  client capture; rejects a shared opaque supplied primary driver; and preserves
  team profile public refusal before any credential lookup.
- `src/uar/runtime/turn/bindings.rs`: carries the nonserializable
  `CredentialSourceDecision` with every bound client, clears `api_key_env` and
  `provider_keys`, uses an explicit empty key for credential-free decisions, and
  sets the existing `host_supplied_connection` flag so builders cannot read
  ambient credentials. Child policies reuse and narrow captured bindings only.
- `src/uar/runtime/manager.rs` test module: replaces the removed legacy
  credential-layer helper coverage with policy-decision fixtures and adds the
  required `CredentialRecord::row_revision: None` fixture field.

Internal interfaces now consumed by the runtime:

```rust
RunManager::with_credential_policy(Arc<CredentialTenancyPolicy>) -> Self
RunModelBindings::capture(
    config: LlmConfig,
    supplied_primary: Option<Arc<dyn LlmDriver>>,
    primary_decision: CredentialSourceDecision,
    fallback_decisions: BTreeMap<String, CredentialSourceDecision>,
    /* existing capture inputs */,
) -> anyhow::Result<RunModelBindings>
```

`CredentialSourceDecision` comes only from `CredentialTenancyPolicy`; it is not
serialized or exposed to children. Run credentials call the policy's
host-restricted explicit-request path only after their existing exact
`config_for` validation. A prebuilt SDK driver has no provenance interface, so
shared policy rejects it; single-owner behavior remains compatible.

Lead-owned L2 still wires direct `/v1/messages` and correction construction
through the same resolution/apply seam. Trust acceptance must include public
shared-denied and authorized `/v1/messages` cases, plus real provider/storage
cases for opaque supplied and inherited bindings.

No test, build, formatter, lint, compiler/import probe, schema validation, or
review ran. The authored fixture coverage and all runtime behavior remain
unverified until the lead records L4 and starts the phase gate.
