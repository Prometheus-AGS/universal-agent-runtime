# T1 source handoff

Stage: Execute. Source authoring only; full-phase implementation boundary remains
closed. No compiler, test, lint, formatter, import probe or independent review ran.

Changed files: `src/uar/security/credentials/policy.rs`, `owner.rs`, `mod.rs`,
`resolver.rs`, and principal-store signature changes in `principal_store.rs`.

Source-grounded reproducer: old resolver fell through every principal miss to
`resolve_system`; issuerless `CredentialPrincipal` retained the fixed global local
JWT/host authority. The prior plan/source recipes remain the pre-fix evidence;
none is an executed exploit result. Compass query failed because installed tool
expects graph-index/1 while snapshot is /2; exact current source was used.

Interfaces exported from credentials: `ProviderCredentialPolicyConfig` (Serde +
JsonSchema), immutable `CredentialTenancyPolicy`, `CredentialOwnerBinding`,
`CredentialSourceDecision`, `CredentialSource`, `CredentialPolicyError`.
`CredentialTenancyPolicy::from_config(config) -> anyhow::Result<Self>` validates
exact grants, canonical optional UUID and strictly loads fixed-local mappings even
without encryption. `bind_principal(&CredentialPrincipal)` / `bind_owner(&UserContext)`
return bound capabilities. General principal encoding is unchanged; lead's
`issuer_kind()` getter distinguishes captured local kinds.

`resolve_source(&self, service: Option<&ProviderService>, principal:
Option<&CredentialPrincipal>, provider_id: &str, endpoint: &str, session_id:
Option<&str>, agent_id: Option<&str>, configured_key: Option<&str>)` asynchronously
returns `anyhow::Result<CredentialSourceDecision>`. Readonly accessors are owner,
provider_id, endpoint, source, policy_revision, api_key. Source enum has
PrincipalSession/PrincipalAgent/PrincipalUser/System/Config/ExplicitRequest/
CredentialFree. SecretString is the only credential-bearing decision field;
Debug omits credentials and endpoints. Runtime must consume before construction,
clear provider_keys/api_key_env and disable ambient loading for every decision.

`explicit_request` is crate-private and only follows the existing host's exact
request-grant validation. Shared identity eligibility still applies. No-service
single-owner house-only capture does not require an unused local namespace; actual
local credential lookup/CRUD still requires provisioned UUID. Resolver now accepts
bound owners and resolves principal scopes only. System source is independently
gated before querying. Errors remain errors rather than fallback misses.

`ProviderService::with_policy(Arc<CredentialTenancyPolicy>) -> anyhow::Result<Self>`
installs validated mappings; `policy()` exposes the handle. Lead constructs policy
independently of `Option<ProviderService>` and supplies it to runtime and API.
`CredentialApiState { policy: Arc<CredentialTenancyPolicy>, service:
Option<Arc<ProviderService>> }` is the concrete router state.

All guards trace to actual credential host/source boundaries. No dependency/pin,
vendor, kernel, generic identity or MCP wire changes. Runtime integration,
constructor ambient suppression and all backend behavior remain unverified until
the lead's full-phase gate. The uncomfortable case remains an alternate client
construction path that fails to consume provenance; runtime/lead own those seams.
