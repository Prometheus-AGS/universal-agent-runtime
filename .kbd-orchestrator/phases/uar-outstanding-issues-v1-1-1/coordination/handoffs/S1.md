`DurableStoreEligibility::as_str()` projects only the closed safe category
`local_durable`, `remote_attested`, `remote_not_attested`, or
`unsupported_backend`; `permits_durable_work()` is true only for local durable
and remote attested stores. The enum is `pub` because it is returned by the
public `PersistenceLayer` trait; it contains no endpoint, namespace,
credential, error, or mutable configuration and does not create a wire field.
Its diagnostic projection methods stay crate-private.

Surreal captures the category once while its provider is constructed:
`surrealkv://` is local durable; a remote endpoint with construction-time
`UAR_REMOTE_SURREAL_DURABILITY_ATTESTED=1` is remote attested; other remote
endpoints are remote not attested; unsupported endpoints and memory are
unsupported. PostgreSQL is local durable. Later health, connection, mutable
configuration, or environment reads cannot upgrade the captured category.
`SurrealHostProvider` records local durable for its trusted embedded host
client.
