# Replacement exit contract — design draft, no execution authority

1. **Identity and scope:** registry version, current source/artifact/config/schema identities, selected platforms/backends/providers and named actual commands. Use a compact relevant source closure and dirty-diff/vendor evidence, not a recursive inventory of unrelated skill/model metadata. Required KBD serialization is generated from this one run plan.
2. **Admission:** all child implementation complete; explicit operator adoption of replacement policy and exact execution approval. Current A22 and AGENTS.md remain effective until then. Child creation neither opens the gate nor resets the parent.
3. **Denominator:** every promised capability/route/mode has a registry cell or a reasoned applicability disposition. Default/custom interfaces, built-in protection and orchestrator selection streams are required. The selected sweep is macOS→Linux→iOS; Windows is outside this sweep with its historical missing-executor blocker retained; Android DEFERRED. A missing cell cannot be hidden in a percentage.
4. **Repetitions:** three fresh positive journeys per acceptance cell; two controlled-fault journeys per resilience cell. Existing documented stricter obligations are retained or explicitly amended, not silently reduced. First diagnostic request is evidence, not complete acceptance.
5. **Inference and outcomes:** genuine configured model for useful-completion claims; task-specific independently checkable predicates, streamed protocol and selection events, persistence/restart and actual strategy effects. Real embeddings for grounding/regeneration. No mock success or HTTP-only oracle.
6. **Resources:** exact maximum model/embedding attempts derived from each scenario's per-journey cap and repetitions, including one same-item rerun. Explicit per-request, per-cell and run deadlines; aggregate tokens/bytes/process resources. Original cumulative calls/time/repairs/UNKNOWNs retained. Execution must fit actual remaining original ceilings or await one explicit amendment. Independent total USD10/provider embedding ceilings include previous reservations; no pool transfer.
7. **Fixture effects:** only named owned local data roots, ports, stores, processes, images and platform tools. Acquire lazily per cell; don't touch operator state. No publication, dependency upgrades or system installs unless individually named. Existing expiring tokens are not silently reused beyond validity; any required scoped issuance is named once in the actual packet.
8. **Failure collection:** PASS→next; FAIL→log, discuss quick fix versus backlog; at most one within-scope ≤15active-minute correction and one rerun under explicitly adopted authority, otherwise continue independent cells. Preserve initial failure. BLOCKED propagates only through actual prerequisites/resource domains. Untrustworthy shared spend accounting stops provider dispatch; unknown ownership/contamination stops affected resources. No automatic unlimited retry.
9. **Evidence:** append-only raw redacted responses/streams and receipts plus compact result index. Include oracles, identity, duration, request/reservation usage, cleanup and correction linkage. Report each source cohort separately; no old-source PASS transfer.
10. **Acceptance:** applicable required functional cells meet their predicates/repetitions, required supporting checks pass, cleanup is confirmed and all failures/dispositions are reported. Platform certification requires actual platform execution. Any unresolved required FAIL/BLOCKED prevents the corresponding certification. Operator may accept a narrower release only through an explicit scope decision and release notes.
11. **Return:** preserve parent receipts and historical obligations, append child findings, reconcile canonical tasks, then propose parent continuation. No archive/reflection or validation claim from planning alone.

This draft deliberately contains no new signature request, fake executable command or adopted budget. The implementation handoff must supply those concrete values once.

## Ordered platform milestones

Execute the complete applicable macOS sweep, then complete Linux, then complete iOS. Finish every runnable current-platform cell and record explicit blocked dependents, bounded correction/backlog disposition and confirmed cleanup before advancing. This milestone does not require falsely labeling unresolved failures PASS; unresolved required failures prevent certification. Prioritize shared defects before the next platform, build its corrected artifacts, and renew affected earlier-platform regression evidence after any later shared fix. No routine platform interleaving. This order does not grant execution authority or expand budgets.
