Writes to the host filesystem. Approval: Ask. Off by default in the runtime config.
Web fetch on
GET a URL and return text. Routed through the same Cedar policy as the inspector browser.
Terminal off
Exposes a shell to the model. Only for sandboxed hosts; the runtime config warns against it. Approval is forced to Ask and cannot be set to Auto.

Run opt-in WASM tool bundles in-process. Schema-validated and policy-gated like everything else; not a release promise.
