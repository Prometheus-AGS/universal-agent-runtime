Knowledge & memory

Two different stores. Knowledge bases hold documents you add; the agent retrieves chunks from them when a question needs it. Memory holds what the agent learned from your conversations, and it is off until you turn it on.

Knowledge base = documents you add

Files are extracted, split into chunks and embedded. At run time the agent searches them and quotes what it finds. Nothing is added unless you upload it.

Memory = what the agent learns

Facts and preferences captured from conversations, then injected into later runs. You never upload to it; you review and forget entries instead.

Memory is off, the default

Nothing from your conversations is captured or injected. 7 memories from an earlier session stay in ./data/memory.db and are used again when you turn memory on.
