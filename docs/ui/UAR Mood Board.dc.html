// Universal Agent Runtime · surface board v1

Every surface, one system

Fourteen panels covering the runtime's user stories end to end — conversation, provider credentials, knowledge, agents, protocols, and policy. Every panel obeys the same rules: charcoal ladder, one ember accent, mono for machine facts, Space Grotesk for names, Roboto for prose. Everything configurable globally is also configurable per agent; the last panel is the reconciliation view.
