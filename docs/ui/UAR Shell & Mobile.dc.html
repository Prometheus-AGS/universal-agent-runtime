// Shell & navigation · desktop + mobile

One container, two form factors

The desktop shell is a three-zone frame: a persistent rail carrying the Slash Gate mark, a context column that changes per destination, and the working surface. On mobile the same information architecture collapses to a top bar plus four tabs, and every desktop side panel becomes a sheet. Nothing is removed — only re-stacked.
