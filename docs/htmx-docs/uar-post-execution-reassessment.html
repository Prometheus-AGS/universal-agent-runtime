§ 02 — Execution Detail

New Capabilities

Implementation details for each of the 7 closed improvement tracks.

Track 1 — deploy.yml
CI/CD Pipeline

Triggers on push to deployment branch. Three-stage pipeline: validate (build + test + lint + frontend), build-and-push (Docker → Docker Hub), deploy (GKE rolling update via kubectl set image).

Image tagged with both deployment-<sha> and deployment-latest. Required secrets: GCP_SA_KEY, GCP_PROJECT_ID, GKE_CLUSTER_NAME, GKE_CLUSTER_LOCATION, DOCKER_USERNAME, DOCKER_PASSWORD.

Impact: Removes the #1 critical gap. Every commit is now automatically tested and deployed.

Track 2 — /mcp/uar
MCP Server

New src/uar/mcp_server.rs (360 lines) using rmcp::tool_router! macro. Mounted at /mcp/uar via StreamableHttpService alongside existing /mcp/memory.

Exposed tools: uar_list_agents, uar_create_run, uar_get_run_status, uar_list_skills, uar_compile_spec.

Impact: UAR is now a full MCP ecosystem participant — other agents can orchestrate it programmatically.

Track 3 — §06 Closed
A2UI / AG-UI Implementation

Backend: a2ui/schema.rs (ArtifactType enum, 5 built-in schemas), a2ui/registry.rs (thread-safe RwLock + HashMap), a2ui/routes.rs (REST: schemas list/get, artifact-response POST).

Events: NormalizedEvent::ArtifactInputRequest → agui.artifact_input_request SSE event. RunDoneWithUsage → agui.done with token counts.

Frontend: <a2ui-artifact> (433 lines) renders form/confirm/select/text-input/display artifacts, submits via POST.

Data collection flow: Agent emits → SSE delivers → component renders → user submits → POST → injected as tool result → agent continues.

Track 4 — Cargo.toml
Dependency Hardening

All 4 git dependencies pinned to exact commit SHAs:

rmcp → 085470025f69…
surreal-memory → c6f95c905c16…
kreuzberg → 000244987eb9…
prometheus_parking_lot → 32b481d6c569…

docs/DEPENDENCY_MANAGEMENT.md created with 6-step upgrade SOP. Build is now fully reproducible.

Track 5 — Surfacing
Memory System Documentation

docs/MEMORY_SYSTEM.md (366 lines) — 10 sections covering Overview, Scopes, Types, Enabling, Auto-Capture, Context Injection, MCP Access, Knowledge Graph, Annotated Config, and Quick Start.

<memory-indicator> (191 lines) — MEM pill showing active scope + record count. Click-to-cycle-scopes. Green/grey state. Backed by GET /api/admin/memories/stats.

Track 6 — Components
Chat UI Improvements

<chat-input-bar> (472 lines) — auto-resize 2–10 rows, left tool slot, right toolbar, file drag-and-drop with preview grid, keyboard shortcuts.

<agent-selector> (286 lines) — pill button, dropdown from GET /api/uar/agents, emits agent-selected event.

<a2ui-artifact> (433 lines) — renders 5 artifact types, submits responses via POST.

Token/cost badge — displayed below each response. Shows in: N tok | out: N tok | ~$0.00X. Sourced from RunDoneWithUsage event.

Track 7 — Local Stack
Production Docker Compose

6 services: postgres (pg17), redis (7-alpine), surreal (v3), surrealist (3.7.2), dbgate (latest), uar (latest).

Named volumes: postgres-data, redis-data, surreal-data, uar-uploads, uar-data.

Health checks on all services mirroring K8s liveness probes. depends_on: condition: service_healthy enforces startup order. Internal uar-net bridge network.

start.sh — checks .env, copies .env.example if missing, pulls images, starts stack, waits for health, prints access URLs. Developer time-to-first-run: ~5 minutes.
