§ 02 — Strategic Licensing

Dual-License Model

The AGPL-3.0 + Commercial dual-license mirrors the same model deployed by MongoDB, MinIO, and SurrealDB. For a local-first agent runtime, it's the optimal balance between community development and commercial viability.

Primary License
AGPL-3.0-only
Network-use copyleft. Any organization that forks UAR and deploys it as a hosted agent service must release their modifications under the same terms. Protects the runtime at the infrastructure layer.
Commercial License
Proprietary Embedding
For organizations that cannot comply with AGPL obligations — proprietary embedding, closed-source SaaS, or managed hosting. Enables enterprise adoption without reciprocal source obligations.

The license field in Cargo.toml is correctly set to AGPL-3.0-only, ensuring crate metadata aligns with the actual license. The commercial license document resides at LICENSE-COMMERCIAL.md in the repository root.

Key Differentiators
01
Specification-Driven. UAR is the only runtime backed by formal specification documents (UAR-AGENT-MD, UAR-GOV). Competitors are framework-first; UAR is spec-first. This is a structural advantage at the enterprise sales level.
02
Governance-First. Cedar-based PDP/PEP is unique among Wasm agent runtimes. Policy Cards (arXiv:2510.24383) validate the approach academically but lack a runtime implementation.

Full-Stack Embedded. Combines Wasm sandbox + Actor model + Cedar governance + RAG + MCP client in a single binary. No surveyed competitor covers all five in one deployable unit.
04
A2A + A2UI. The UAR-AGENT-MD spec defines both agent-to-agent and agent-to-UI contracts. This is absent from all competitors surveyed. A2UI in particular is a forward-looking capability for dashboard and Cherry Studio integration.

§ 06 — Strategic Roadmap · Next Horizons

Recommendations

With Phases 1–4 complete, the following initiatives represent the next layer of specification implementation and ecosystem positioning.

High
UAR-AGENT-MD Compiler
Implement the full 8-stage compilation pipeline defined in UAR-AGENT-MD § 19. The spec is detailed and ready. A uar compile agent.md CLI that validates, cross-references, and produces signed agent descriptors would close the largest remaining specification gap and create a clear developer on-ramp.
Medium
A2UI Schema Registry
Implement A2UI schema resolution (UAR-AGENT-MD § 06). Agents would declare UI surfaces that frontends — Cherry Studio, web dashboards — can resolve and render dynamically. Direct dependency for Cherry Studio integration.
Medium
Governance Admin Surface
Implement the CLI and API for policy simulation, validation, and rollback as defined in UAR-GOV § 4.1 Component 06. Add uar policy simulate and uar policy explain commands for governance debugging and audit trail presentation.
Low · Strategic
WASM Component Model Migration
Evaluate migration from WASI Preview 1 to the WASM Component Model (as deployed by Asterbot/asterai). The Component Model enables typed imports/exports and multi-language components, directly aligning with the A2A contract model defined in the spec.
Low · Research
Policy Cards Integration
Investigate integration with the Policy Cards standard (arXiv:2510.24383). UAR's Cedar-based governance model could export and import Policy Cards for cross-platform governance portability — a strong differentiator for enterprise procurement.
