System Documentation

Memory System

Production-grade, multi-scope agent memory built on surreal-memory and SurrealDB. Durable, cross-session recall that turns stateless LLMs into agents that remember users, learn from interactions, and build a persistent knowledge graph over time.

surreal-memory Hybrid BM25 + Vector 5 Memory Scopes Knowledge Graph MCP Native Opt-In
01
Auto-capture — extracts important facts from each assistant response
02
Context injection — injects relevant memories into the system prompt before each LLM call
03
Hybrid search — vector similarity + BM25 full-text, ranked by recency and importance
04
MCP tools — all operations exposed so agents can read, write, and delete memories mid-conversation
05
Knowledge graph — entities, relationships, and observations built over time
§ 01 — Data Model

Memory Scopes

Every memory record is tagged with a scope that determines its lifetime and access boundary. At injection time, UAR retrieves memories ranked across all scopes, weighted by relevance — with session and user scopes given higher weight for personalization.

ScopeContextLifetimeBest For
session Current conversation ID Until session ends or cleared Immediate context — user intent for this chat
user User ID Permanent (until deleted) Persistent preferences, facts, history
agent Agent ID Permanent (until deleted) Agent-specific knowledge, domain facts
global None Permanent, shared Cross-agent shared knowledge, org-wide facts
task Task stream ID Until task completes Multi-step workflow state, intermediate results

Memory Types

The memory_type field is optional on write — UAR auto-classifies if not specified.

Episodic
Facts & Events
Facts from past conversations. "User prefers dark mode", "Called API at 3pm on Feb 20".
Semantic
Knowledge Graph
Structured entries — entities (User, Product), relations (works_at, prefers), observations.
Procedural
Learned Patterns
Instructions and workflows. "When user asks about billing, always check Stripe".
Associative
Concept Links
Connections between concepts. "Topic X relates to Topic Y based on conversation history".
§ 02 — Configuration

Enabling Memory

Default State
Memory is disabled by default. Set UAR_MEMORY__ENABLED=true to activate it. An embedding provider is required — the default is OpenAI's text-embedding-3-small.
toml # config.toml [memory] enabled = true embedding_provider = "openai" embedding_model = "text-embedding-3-small" auto_capture = true inject_context = true
bash UAR_MEMORY__ENABLED=true UAR_MEMORY__EMBEDDING_PROVIDER=openai # openai | cohere | local UAR_MEMORY__EMBEDDING_MODEL=text-embedding-3-small OPENAI_API_KEY=sk-... # required when provider=openai
ProviderRequired Env VarNotes
openai OPENAI_API_KEY Default. Uses text-embedding-3-small
cohere UAR_MEMORY__COHERE_API_KEY Use embed-english-v3.0 or multilingual equivalent
local — Requires local embedding server at UAR_MEMORY__LOCAL_EMBEDDING_URL
§ 03 — Background Extraction

Auto-Capture

When auto_capture = true (the default when memory is enabled), UAR automatically extracts and stores key facts from each assistant response without the agent needing to call any tool.

Pipeline

1
Extraction Prompt
After each assistant turn completes, the auto-capture pipeline sends the response + conversation context to the LLM with a fact-extraction prompt.
2
Fact Identification
The LLM identifies facts worth remembering — user preferences, stated facts, decisions made.
3
Embed & Store
Each fact is embedded and stored in scope = "session" or scope = "user" depending on content classification.
4
Deduplication
Duplicate facts are detected via embedding similarity and merged or skipped to prevent memory bloat.
Manual-Only Mode
To disable auto-capture while keeping memory enabled, set UAR_MEMORY__AUTO_CAPTURE=false. Agents can still use MCP tools to manage memory explicitly.
§ 04 — Prompt Augmentation

Context Injection

When inject_context = true, UAR prepends a structured memory block to the LLM's system prompt before each call. The injected block is scoped, timestamped, and relevance-scored.

Injection Format

injected prompt ## Recalled Memories 1. [user/2025-11-01] User prefers responses in bullet points. (relevance: 0.94) 2. [session] User is asking about the quarterly report. (relevance: 0.87) 3. [agent] This agent specializes in financial data analysis. (relevance: 0.81)

Tuning Parameters

ParameterDefaultEffect
max_context_tokens 2000 Max tokens reserved for memory context. Increase for deeper recall; decrease to leave room for content.
vector_weight 0.7 Semantic similarity weight. Higher values favor meaning-based matches.
bm25_weight 0.3 Keyword match weight. Must sum to 1.0 with vector_weight.
toml [memory] inject_context = true max_context_tokens = 2000 # Max tokens for injected memories vector_weight = 0.7 # Semantic similarity weight (0–1) bm25_weight = 0.3 # BM25 keyword weight (0–1, sum=1)
§ 05 — Tool Integration

MCP Access

The memory system is exposed as a full MCP server at /mcp/memory. Any MCP-compatible client — Claude Desktop, LangGraph, AutoGen, Cursor — can use all memory tools directly.

toml [memory] mcp_http_enabled = true mcp_http_path = "/mcp/memory" # default

§ 06 — Graph Intelligence

Knowledge Graph

A structured entity-relationship model on top of the scoped memory system. Enables graph-RAG workflows where agents reason across connected entities.

Conceptual Model

Usage Example

python · mcp tool calls # Create an entity with observations kg_create_entity( name="Alice", entity_type="user", observations=["Alice works at Acme Corp"] ) # Define a relationship kg_create_relation( source="Alice", relation_type="works_at", target="Acme Corp" ) # Later, in a new session — expand the graph kg_expand_neighbors(entity="Alice") # → Returns: Acme Corp, Bob, ...
Visual Explorer
Surrealist (included in the Docker Compose stack) provides a visual graph explorer. Connect to ws://localhost:8000 with your SurrealDB credentials to browse the knowledge graph interactively.

§ 08 — Getting Started

Quick Start

Five steps from zero to durable agent memory.

1
Enable Memory
bash export UAR_MEMORY__ENABLED=true export OPENAI_API_KEY=sk-...
2
Start UAR
bash docker compose -f docker-compose.prod.yml up -d # or: cargo run
3
Run Your First Conversation
Send a message through the web UI or via the API:
bash curl -X POST http://localhost:1906/api/uar/runs \ -H "Content-Type: application/json" \ -d '{"agent_id": "your-agent-id", "input": "My name is Alice and I work at Acme Corp."}'
4
Verify Recall
After the run completes, check what was remembered:
bash # Via the memory admin API curl "http://localhost:1906/api/admin/memories?scope=session"

Or connect Claude Desktop to the MCP endpoint and call memory_list — you should see the extracted fact about Alice.

5
Inspect the Knowledge Graph
Start a new conversation and ask: "What do you know about Alice?" — UAR will inject the recalled memory and the agent answers with the stored fact, even in a brand new session. To explore visually, open Surrealist at http://localhost:8080 and connect to ws://localhost:8000.
