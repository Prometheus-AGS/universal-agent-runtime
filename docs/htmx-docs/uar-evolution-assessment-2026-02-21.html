Executive Summary
The Universal Agent Runtime has significantly expanded since its Feb 18 post-Phase-9 assessment. Five new system-level capabilities have been implemented: a full agent memory system (surreal-memory, hybrid search, auto-capture, MCP server, context injection), context window management (sliding window and summarization strategies), enhanced SSE/AG-UI event model (MemoryMutation, ContextAction, StatePatch events), a settings management layer, and expanded MCP tool integration for memory operations. The project now stands at 191 Rust source files (~56,571 lines), 42 TypeScript web components, and 18 integration test files. Its core technical moat — a specification compiler, Cedar governance, A2A federation, and WASM sandboxing — remains intact and uncontested in the market.

The memory system (src/uar/memory/) is a major addition — six files implementing a full agent memory facade over surreal-memory SurrealStorage.

service.rs
MemoryService Facade
Full facade over SurrealStorage — hybrid BM25+vector search, waterfall scope resolution (session → user → agent → global), knowledge graph, mind maps, task streams.
context_builder.rs
Pre-Prompt Context Injection
Composite re-ranking (importance×0.4 + recency×0.35 + access_frequency×0.25), token budget enforcement (10% of model context window), model-profile-aware token counting.
auto_capture.rs
Async Background Capture
Async background memory extraction after assistant turns. Runs without blocking the response pipeline.
mcp_server.rs
MCP Memory Operations
Memory operations exposed as MCP tools over HTTP (/mcp/memory). Full tool discovery and invocation support.
scopes.rs
Scope Abstraction
Session, user, agent, global, and task scopes — supporting multi-tenant waterfall resolution patterns.
background.rs
Background Processing
Background processing task management for long-running memory operations.

Quality assessment: High. The context injection with composite scoring and token budgeting is production-grade. The waterfall scope resolution is well-designed for multi-tenant use.

Gap: Default enabled: false is correct, but enabling memory requires configuring embedding_provider (defaulting to openai). A cold-start without an OpenAI API key will silently not have memory. Documentation on memory enablement is thin relative to complexity.

The NormalizedEvent enum now has 13 variants (up from ~9 at Feb 18). All variants have corresponding agui.* event name mappings via to_agui_event().

A2UI Runtime Gap

NormalizedEvent::Artifact returns None in to_agui_event() — artifact events are silently dropped rather than mapped to an agui.artifact event. This means agents declaring A2UI surfaces in UAR-AGENT-MD cannot dynamically render UI surfaces. The AG-UI protocol's artifact channel is not connected. This remains the single open UAR spec section (§06).

§ 04 — Market Positioning

Product-Market Fit Assessment

Embedded-First Architecture
Fit: High
52% of enterprises cite security/compliance as the #1 barrier to agentic AI production. Embedded-first directly addresses data sovereignty. Risk: enterprise evaluators may equate "production-ready" with "Kubernetes-native."
AGPL-3.0 Licensing
Fit: Medium-Risk
Competitors (Agentgateway, AGNTCY, LangGraph, CrewAI) use Apache-2.0. Enterprise procurement often blocks AGPL. Commercial dual-license terms are not documented in the repository — silent enterprise blocker.
UAR-AGENT-MD Format
Fit: High
AGNTCY OASF (YAML/JSON) gaining LF backing. Markdown wins for LLM-native authoring. No competitor has a compiler for agent specs — UAR-AGENT-MD + 8-stage compiler is unique.
Dual-Mode Compiler
Fit: High
First-mover in LLM-interactive spec authoring. Anthropic 2026 documents the shift from single agents to agent teams — automated creation pipelines are an emerging need with no market equivalent.
Memory System
Fit: High
Hybrid BM25+vector search, knowledge graph, multi-scope architecture (session/user/agent/global) is more sophisticated than most agent frameworks. Memory cited as top differentiator for 2026 production agents.
