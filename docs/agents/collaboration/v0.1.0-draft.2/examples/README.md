# Valid draft.2 examples

These examples cover every concrete schema selected by `collaboration-document.schema.json`. They use ASCII keys and integer numbers so their canonical content digests are unambiguous. Package byte digests cover the exact checked-in UTF-8 bytes of its AgentDefinition, TeamDefinition, and WorkflowDefinition files.

The examples are documentation fixtures. They do not prove runtime schema registration, binding, admission, team execution, or C17 behavior.
