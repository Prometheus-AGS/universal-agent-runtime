# UAR v1.2.1 — functional acceptance pending

This release source implements caller-owned tools across OpenAI Chat
Completions, Anthropic Messages, AG-UI, A2A 1.0, and ACP. The operator requested
immediate source-tag and Docker publication before functional acceptance. The Intel macOS development binary built successfully with
`server-full,postgres-backend` (active-phase build003 receipt). No image, digest,
source tag, or functional acceptance is established by this document. The historical v1.2.0 release and its immutable
image remain described by their original release documents.

The active KBD phase is `uar-post-lifecycle-verification-readiness`, Execute,
with change `openai-client-tools`. The source package version is
1.2.1; publication receipts and the resulting index digest are recorded separately.

The candidate accepts caller function declarations and selection controls,
returns calls for the application to execute, and admits exact result batches
through durable, authenticated continuation records. Host tools retain their
existing executable registry, policy, approval, and MCP interaction paths.
Caller descriptions do not register host executables or approve host actions.

The [candidate Kubo contract](v1.2.1-kubo.md) defines each wire shape, provider
control restrictions, replay semantics, and authored acceptance entry points.
The five interfaces use their native result conventions; they do not share one
invented wire protocol. AG-UI reports native frontend handoffs with
`pendingToolCallIds`; A2A reports `InputRequired`; ACP exposes its explicit
caller-tools JSON-RPC extension.

The important limitation is that functional acceptance has not run. The Intel
macOS development binary compiled and linked; Linux amd64/arm64 publication
builds are separate from product acceptance. Native protocol behavior, durable
restart, graph continuation and cumulative budgets remain unverified. No earlier
1.2.0 acceptance or build receipt certifies this release.

Publication targets `ghcr.io/prometheus-ags/universal-agent-runtime:1.2.1`
and `ghcr.io/prometheus-ags/universal-agent-runtime:v1.2.1`, with git tag `v1.2.1`
at the release commit. The canonical image index is pending publication; do not
substitute the frozen 1.2.0 digest. The 1.2.0 image and tags remain unchanged.
