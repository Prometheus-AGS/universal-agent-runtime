## Integration changes
Streaming `/v1/chat/completions` emits terminal `budget_error` objects and `[DONE]` without claiming a successful stop. Client-supplied OpenAI tools are not forwarded; AG-UI rejects frontend tools. This release also records MCP catalog hydration and retained transport cleanup, credential tenancy/migration APIs and authenticated capture, and retained AG-UI terminal projection. The attached `v1.2.0-kubo.md` defines every requested Kubo surface, its change since v1.1.0, and integration limits. OpenAI request `model` selects a registered agent ID (or default/orchestrator alias), not a provider/model pair; LLM_MODEL configures the underlying provider separately. No later client-tools capability change is scheduled by this work.
