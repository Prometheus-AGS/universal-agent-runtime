# UAR 1.4.0-rc.6 candidate notes

**Candidate, 2026-11-22. Not qualified, tagged or published.**

## What changes for users

- **Live model choice.** An operator changes the system default without a
  restart. A conversation can override it and clear the override. Each reply
  names the model the provider reported. Switching a provider's default model
  no longer discards that provider's verification proofs, which had sent the
  next reply to the configured fallback model.
- **Saving a provider without a key** keeps the saved key. It no longer
  replaces it with, or stores, the key in that provider's environment
  variable.
- **Start UAR from another program** (#539) with
  `universal-agent-runtime --supervised --port 0`. See
  [Starting UAR from another program](../operations/supervised-launch.md).
- **`GET /api/uar/version`** reports the version, source commit, features and
  protocol versions, so an installer can check what is running.
- **Console.** The model catalog stays responsive with the full catalog, and
  the first chat in a new browser no longer needs a reload.
- **Rate limit.** The default burst rises from 20 to 100. An exposed server
  admits up to 100 requests at once before it throttles.
- **Images.** The amd64 and arm64 builds are repaired, and an image records
  its source commit.

## Before you upgrade

- An existing native install keeps its `config.yaml`, and with it a burst of
  20. Set `resilience.burst_size: 100.0` there, or reloading a console page can
  return 429.
- A host that starts UAR must set both `models.models_dir` and
  `llm.embedding.models_dir`, or set `UAR_MODELS_DIR`.

## Known limits

- The live-model-choice scenarios have not passed on this candidate, and
  neither image has been built from it.
- Eight older `sidecar_launch_security` cases fail, with the same messages as
  on 1.4.0-rc.5 source at `0ce227af`. Until each is decided, that suite does
  not show that those eight supervised-mode controls work.
- The rate-limit values saved in Settings do not affect the running limiter,
  which reads its start-up configuration.
- The Boss sidecars are separate builds and are not rebuilt by this candidate.
- 1.4.0 final remains unqualified. See the
  [final checklist](v1.4.0-final.md).
