# UAR 1.4.0 final — bounded acceptance checklist

Status: **source preparation; no final release qualification or promotion**. This is the current finite checklist requested by #465, continuing the transferred [rc.2 final checklist](v1.4.0-rc.2.md#140-final-checklist) and #421. Historical rc.1/rc.2 receipts remain unchanged. KBD's `production-readiness-476` waypoint and whole-set #462–#475 implementation ledger remain authoritative; this document does not create another phase system, runner or permission to execute checks.

The selected first profile is **Linux amd64 root-Dockerfile `server-full,postgres-backend` container APIs behind a trusted host/gateway**, with embedded SurrealDB 4.0.0 on owned SurrealKV volumes by default. Restricted PostgreSQL18 is a secondary profile only within the [store capability contract](../operations/persistence-capabilities.md). Functional/manual cases use the externally provisioned identity endpoint and nonsecret base URL/model/workspace selectors; tests do not obtain or send authentication credentials. A local gateway fixture does not certify remote multi-user admission or a production gateway deployment.

All prior gate017 permissions are revoked. Complete all phase implementation, then freeze the source/config/artifact inventory and request explicit approval for **one named final validation batch**. No checklist row, passing historical receipt or writer handoff opens that gate. Subsequent source edits require renewed inventory and approval. The mandatory local GitHub Actions policy validator is deferred to that final batch by the operator's ALL-code-FIRST instruction; it is not waived and must precede publication. Product testing stays local. Publication, signing, deployment and paid model use require their applicable explicit authority.

Only the approved exact-artifact final observations can support those claims.
