# UAR v1.2.3 integration contract

This patch preserves the caller-executed tool loop on OpenAI Chat Completions,
Anthropic Messages, AG-UI, A2A and ACP. Caller functions are returned to the caller
for execution; separately admitted host tools retain their governed execution.
The wire payloads and controls remain described in [v1.2.1-kubo.md](v1.2.1-kubo.md),
with the production-path corrections in [v1.2.2-kubo.md](v1.2.2-kubo.md).

## Acknowledgment correction

Observers of one live source run serialize handoff acknowledgment. Each still
requires the exact owner/tenant/agent/run durable batch, real root and delegated
child cleanup where applicable, and committed source-settled acknowledgment.
Current credentials, policy, tool bindings and full matching result batches
remain required for continuation. Completed identical retries retain recorded
replay without another provider call or host effect. A cold process can rely
only on previously committed settlement evidence; an absent live source cannot
create that evidence.

AG-UI's retained observer and HTTP stream previously could issue competing
acknowledgments. Published1.2.2 testing observed one failure terminal and a
separate mixed-call run in which a confirmation warning coexisted with a winning
success terminal. The original warning discarded the underlying error; this
contract does not claim that its precise inner failing operation was proven.
Fixed-stage diagnostics now identify future confirmation failures without
logging arbitrary backend text, credentials or tool payloads. Real cleanup or
storage failures still fail closed.
