# UAR 1.4.0-rc.1 — release candidate

**Status:** release candidate. The macOS catalog below is historical, accumulated evidence across recorded binaries; it does not certify the current source or one final artifact. The first selected #476 production contract is **Linux amd64 container APIs**, with SurrealDB3.3.0 default and PostgreSQL18’s explicit restrictions. Exact image/API/recovery qualification remains pending #465.

## What changed since v1.3.0

- **A2UI on the AG-UI route.** Published A2UI batches become AG-UI
  `ACTIVITY_SNAPSHOT` events with a stable per-surface `messageId`. Each run
  restates the conversation's live surfaces. `forwardedProps.a2uiAction` starts
  a new run on the same thread; an undeclared action (422), an action with new
  user text (400) or an orchestrator target (422) is refused.
- **Fixes found by BDD.**
  - TypeScript SDK streaming parses SSE with `fetch` alone; the previous
    dependency crashed in Node.
  - ACP `runs/get` returns `output` once a non-streamed run is done.
  - `intent_classifier.*` settings are read on each turn instead of being inert.
  - The localembedding classifier rescales confidence from the unrelated-cosine
    floor; the llm classifier ignores reasoning events and strips inline
    `<think>` and one code fence.
- **Document extraction.** kreuzberg 4.10.4 is replaced by xberg 1.4.0 from
  `Know-Me-Tools/xberg` at rev `ffb3b1a25b6c14c13858142997dd82a16d5b2f35`.
  kreuzberg-tesseract 4.10.4 no longer builds against zip 9.1.1 and later.
  UAR's `kreuzberg` provider value, settings namespace, route and config section
  keep their names.
- **Dependencies.** Latest compatible versions across Cargo and the React
  console, including wasmtime 50, OpenTelemetry 0.33/0.34, utoipa 6, sqlx 0.9,
  argon2 0.6, TypeScript 6.0.3 and PEM 4.3.0. `versions.toml` pins are held.

## Known limits

The rc.1 record leaves these scenarios blocked. Current #463/#464 source work is not acceptance; status changes require actual scoped replacement receipts.

- **E04, capability-constrained routing.** Run dispatch uses default route
  requirements; `POST /api/uar/route` answers a query but does not steer runs
  and has no exclusion parameter.
- **E06, vision, and E07's image half.** The recorded ordinary OpenAI path dropped image parts or sent descriptive JSON text. The new bounded inline PNG/JPEG path is authored but NOT_EXERCISED. Existing direct Anthropic conversion is implemented and independently unqualified, so the old blanket claim that no public image path exists is too broad. No genuine visual-fact qualification follows from catalog flags, byte capture or canned answers.

Other limits carried from the validation record:

- xberg's chunker uses `icu_segmenter`, so chunk boundaries can differ from
  kreuzberg on large documents. Office, spreadsheet, email, archive and OCR
  extraction have no BDD scenario.
- A retried A2UI click with a new run id acts twice; surfaces more than 64 runs
  back are not restated.
