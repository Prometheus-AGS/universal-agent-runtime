# UAR 1.3.1 — native tool-call identity

UAR 1.3.1 is a patch release of 1.3.0. It carries one correction: native tool calls keep their identity from the model stream through approval, execution, recovery and canonical persistence. The root package becomes 1.3.1; independently versioned applications keep their own versions.

## Predecessor

UAR 1.3.0 is unchanged: tag `v1.3.0` at `774469746fee4de99be41dc1cd231857067e4487` and OCI index `sha256:f67a36f1a6fb886379c6947f605a88945a94481c8b3c4e1d998b9b481cea0697`. The `v1.3.0-publication-001` to `-003` tags also remain. Kubo's real-UAR native acceptance of 1.3.0 failed. An approved native tool executed with an empty tool-call ID, and resume then failed with `canonical_receipt_invalid_message`. The 1.3.0 source also overwrote an accumulated ID with empty continuation IDs.

## What changes

- Authentic nonblank call IDs are preserved across stream fragments, and conflicting identities are rejected.
- The complete native batch is validated before approval or execution, and the admission authority envelope requires a nonblank model call identity.
- Normalized identity is published outward on public deltas and completions, with the original indexes.
- Client-owned host IDs, canonical receipts, checkpoint binding, policy, denial and replay protections are unchanged.

Source: OpenSpec `preserve-native-tool-call-identity`, the corrected "r14" source tree `7d3177b2b6ff8a3c70c6b7de1d21ff05e33f51bd`, applied unchanged on `v1.3.0`. No dependency, schema, public API, provider/model route, UI or vendored source changes. The only additional 1.3.1 changes are the root package version in `Cargo.toml` and `Cargo.lock`, and this note.

## Verification status

This note claims no product acceptance of a 1.3.1 image. The source's earlier scoped library, admission, protocol and client results are recorded in the OpenSpec change under their original revisions; they do not certify this release. Whole-workspace formatting, the mandatory T2 suite's `postgres-backend` target routing, warnings, and Kubo's real-UAR native acceptance remain open release gates.
