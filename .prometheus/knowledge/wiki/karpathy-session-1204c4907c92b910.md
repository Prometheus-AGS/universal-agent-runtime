The main change from revision 1 is that existing keys are left alone. Revision 2:

- **keeps every existing owner-key format and `storage_key()` unchanged;**
- **separates the key from authority:**
  - presented tokens can only determine whose data a request touches;
  - roles, host authority, instance delegation and shared provider keys come only from a verified identity, which the types enforce at compile time;

- `single_user` ignores tokens for identity.
- The trust check reads the actual bound sockets, not a config string.
