# Support

_Last updated: 2026-07-10._

## Community support (free)

- **Bug reports / feature requests:** [GitHub Issues](https://github.com/Prometheus-AGS/universal-agent-runtime/issues)
  using the provided templates.
- **Questions / discussion:** [GitHub Discussions](https://github.com/Prometheus-AGS/universal-agent-runtime/discussions).
- **Security reports:** never via public issues — see [SECURITY.md](SECURITY.md).

Community support is best-effort. We aim to triage new issues within a week;
there is no guaranteed response or fix time on the community track.

## Commercial support

Commercial licensees (see [LICENSE-COMMERCIAL.md](LICENSE-COMMERCIAL.md) and
[docs/LICENSING.md](docs/LICENSING.md)) receive contractual response times,
upgrade assistance, and deployment guidance. Contact: the licensing contact
listed in LICENSE-COMMERCIAL.md.

## Supported versions

Security and bug fixes target the latest 1.x release. See
[SECURITY.md](SECURITY.md) for the security-support matrix and
`docs/` for upgrade guidance.
