# Specification — UAR architecture-history review

- Artifact name: `uar-architecture-history-review`
- Artifact type: `content`
- Content type: `direct:content`
- Intent: review the completed public architecture history for traceability,
  supersession, source safety, current-authority boundaries, and evidence limits.
- Code execution required: yes, for source, manifest, negative-control, and
  composition validation.

## Target state

1. All 18 retained ADRs are indexed without conflating `ADR-007` and `ADR-0007`.
2. Seven selected corrections identify both the replaced position and current
   authority.
3. Public prose preserves licensing, frontend, visual, JWT, publication,
   verification-location, and inference-evidence reversals.
4. Raw Prometheus/KBD content and wiki projections remain synthesis-only.
5. Current behavior remains subordinate to current source, canonical
   specifications, and profile-specific evidence.

## Limits

- The selected public history is not the complete 546-file retained corpus.
- Source existence does not prove that the source still describes implementation.
- Production build, browser, accessibility, deployment, and runtime behavior are
  outside this content review.
