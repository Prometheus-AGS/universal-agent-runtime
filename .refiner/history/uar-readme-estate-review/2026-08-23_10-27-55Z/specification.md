# Specification — UAR README estate review

- Artifact name: `uar-readme-estate-review`
- Artifact type: `content`
- Content type: `direct:content`
- Intent: review the completed README and bounded portal-source reconciliation
  for accuracy, ownership, public safety, profile limits, and frozen navigation.
- Code execution required: yes, for manifest/control/link/schema validation.

## Target state

1. Every tracked README has exactly one ownership record and a current or
   historical authority.
2. Current files describe checked-in behavior without presenting source metadata,
   response doubles, or package manifests as availability evidence.
3. Historical/unshipped systems remain visibly superseded and do not compete
   with the current portal.
4. Private evidence, raw payload sources, machine paths, and credentials do not
   enter direct public output.
5. All required frozen Docusaurus document IDs exist without editing the frozen
   route, shared navigation, or theme contracts.
6. Production build, rendered UI, accessibility, deployment, and live-route
   claims remain deferred to final documentation certification.

## Unknowns and limits

- Vale is not installed, so prose lint is not evidence for this change.
- The Pages deployment and live routes are not exercised in this content lane.
- Runtime, inference, registry, and cross-profile behavior are outside this review.
