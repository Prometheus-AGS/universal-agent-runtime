# Specification — `fix-embedded-sse-offline-reconnect`

The final candidate must deliver valid named embedded SSE entity changes once,
recover through one closed-before-replacement connection, cancel recovery on
unsubscribe, and demonstrate the registered application adapter changing
visible Knowledge state before and after forced error. Existing-ID entity
reactivity belongs in the upstream normalized React projection. Preparation
must build its source dependency graph. The receipt must preserve the unrelated
full-suite failure and must not claim replay, lossless offline delivery, npm
publication, or parent screen certification.
